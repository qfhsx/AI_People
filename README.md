# AI Digital Human Education Video Generator (Feasibility Version)

## Prerequisites
- Python 3.9+
- Node.js 14+
- (Optional) Volcengine AccessKey/SecretKey for real generation

## Quick Start

### Mac/Linux
```bash
chmod +x start.sh
./start.sh
```

### Windows
Double click `start.bat`

## Access
- Frontend: http://localhost:3000
- Backend: http://localhost:5000

## Configuration
Edit `backend/app/config.py` to add your Volcengine keys.
If keys are not set, the system runs in Mock Mode (generates video without digital human).
